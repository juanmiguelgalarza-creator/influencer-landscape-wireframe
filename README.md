# Influencer Landscape — Wireframe

Wireframe de baja fidelidad (blanco / negro / grises) de una plataforma para explorar y contratar influencers, con saldo en tokens, perfiles y flujo de cobro.

**Autor:** Juan Miguel Galarza — Diseño UX/UI

## Ver el proyecto

Es un único archivo HTML autocontenido (sin dependencias). Abre `wireframe.html` en cualquier navegador.

## Decisiones de diseño

- Sin color: el estado se comunica con relleno vs. contorno, línea sólida vs. punteada y opacidad.
- Tipografía monoespaciada para mantener el foco en estructura y jerarquía, no en estilo visual.
